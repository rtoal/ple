# Logo Explorations

To run Logo programs on your local machine, download and install software from the [FMSLogo downloads page](
https://fmslogo.sourceforge.io/).

To run these Logo programs on the FMSLogo software, click on "File" in the homepage, then in the dropbox, select "Open...," then choose an example file inside of this folder to run the program.

## About

Logo is a Lisp-dialect educational programming language aimed to have a "low threshold and no ceiling." It was created from the MIT Artificial Intelligence Laboratory in 1967. Known for the Turtle program that draws lines on a canvas by giving it directions, this language became widespread which led to the creation of the nonprofit Logo Foundation, which aims to create Logo professional development around the world. In 2004, Scratch was created, which replaced the standard typed language with a visual block-based programming language.
